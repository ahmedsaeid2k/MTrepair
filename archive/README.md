# مجلد الأرشيف التاريخي (Historical Archive) — microERP

> **تنبيه هام:**  
> كافة الملفات داخل هذا المجلد هي ملفات تاريخية قديمة (Legacy Archive) غير مستخدمة إطلاقاً في بيئة الإنتاج أو التطوير الحالية.  
> المصدر الوحيد المعتمد للشفرة البرمجية والتطوير هو مجلد **`app-modular/`**.  
> عملية البناء والتجميع تتم حصراً عبر: `node app-modular/build.js` وتُنتج ملف `app-modular/dist/index.html`.

## محتويات الأرشيف:
1. **`legacy-monolith.html`**:
   - النسخة الأحادية القديمة للمشروع (Monolithic SPA) قبل تفكيكها ونقلها إلى الهيكل المعياري `app-modular/`.
   - تم الاحتفاظ بها كمرجع تاريخي بعد إيقاف وحذف سكريبت المزامنة العكسية غير الآمن `sync-modular.js`.

2. **`mterpkernal/`**:
   - مسودة تجريبية سابقة تم تشعيبها أثناء مرحلة التطوير الأولى.
   - تحتوي على ترقيم قديم ومسارات غير متطابقة، وتمت أرشفتها لمنع أي خلط أو تعديل خاطئ من قبل المطورين أو الوكلاء الأذكياء.
