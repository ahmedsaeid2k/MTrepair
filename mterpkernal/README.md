# دليل نواة النظام الموحدة القابلة للتشكيل (mterp Kernel)

مرحباً بك في **mterp Kernel** — النواة البرمجية الموحدة لأنظمة تخطيط موارد المؤسسات (ERP Engine)، المصممة خصيصاً لتكون **محايدة وقابلة للتشكيل والتخصيص الفوري (Configurable & Pluggable)** لتناسب أي نشاط تجاري، مهني، أو خدمي.

---

## 🌟 الفكرة المعمارية والجوهرية

كل الأنشطة والمؤسسات التجارية والخدمية (تجزئة، صيانة، مطاعم، صيدليات، مقاولات، خدمات عامة) تشترك في 9 أركان رئيسية:
1. **العملاء (CRM & Customers):** سجل الاتصال، الرصيد، كشوف الحساب، رسائل الواتساب.
2. **الموردون (Suppliers):** فواتير الشراء، مدفوعات الموردين، وإدارة المديونيات.
3. **الصلاحيات والمستخدمين (RBAC):** مدير، كاشير، محاسب، مشرف، موظف مبيعات.
4. **كادر العمل والموظفون (Staff & Commissions):** إدارة الموظفين، نسب العمولات، السلفيات النقدية.
5. **المخازن والمستودعات (Multi-Warehouse Inventory):** الأصناف، الباركود، التحويلات المخزنية، الجرد.
6. **الرقابة والإشراف (Audit Trail & Supervisor Approvals):** سجل الرقابة الشامل وصندوق تصاريح الحذف بالصوت (Audio Chime).
7. **الخزينة والورديات (Cash Drawer & Treasury Shifts):** فتح وإغلاق الوردية، المصروفات، وتتبع السيولة.
8. **منظومة طرق الدفع المتعددة (Multi-Payment Methods):** نقدي، فيزا وبطاقات، محافظ إلكترونية، إنستاباي، ودفع آجل/على الحساب.
9. **محرك الواجهة والطباعة (UI Themes & Printing):** ثيمات متطورة (Odoo, Apple, Glassmorphism, Win11)، طباعة حرارية 80 مم، A4، A5، باركود، ولوحة تحكم سريعة (Cmd + K).

## 🚀 كيفية التشغيل والتطوير

### 1. وضع التطوير الموديولي (Modular Development Mode)
افتح الملف:
[`mterpkernal/index.html`](file:///Users/M1/Desktop/microtech-app/mterpkernal/index.html)
مباشرة في المتصفح أو عبر أي خادم ويب محلي. يمكنك تعديل أي ملف في `js/` أو `css/` لرؤية التغييرات فوراً.

### 2. وضع التجميع والإنتاج (Production Bundle Mode)
عند رغبتك في توليد ملف واحد مدمج محمي للتشغيل بدون الحاجة للمجلدات:
افتح الطرفية (Terminal) واكتب:
```bash
node mterpkernal/build.js
```
* سيتم فحص ودمج كافة ملفات CSS و JavaScript والتحقق من صحتها برمجياً (Node.js Syntax Verification).
* الملف النهائي ينتج في: [`mterpkernal/dist/index.html`](file:///Users/M1/Desktop/microtech-app/mterpkernal/dist/index.html).

## 🎯 كيفية إضافة نشاط جديد في 3 دقائق

لإضافة نشاط تجاري جديد (مثلاً: نشاط صيدليات ومستلزمات طبية `pharmacy`)، أنشئ ملفاً جديداً في `js/profiles/profile-pharmacy.js`:

```javascript
registerActivityProfile({
  id: 'pharmacy',
  name: 'الصيدليات والمستلزمات الطبية',
  icon: '💊',
  desc: 'إدارة مبيعات الأدوية، المستلزمات الطبية، الصلاحيات وتواريخ الانتهاء، والموزعين.',
  primaryColor: '#059669',
  activeSections: ['pos', 'invoices', 'inventory', 'cashdrawer', 'daily', 'finance', 'staff', 'customers', 'suppliers', 'barcode', 'audit', 'users', 'settings'],
  terms: {
    staffLabel: 'فريق الصيادلة والمساعدين',
    staffSingle: 'صيدلي',
    itemLabel: 'الدواء / المستلزم الطبي',
    ticketLabel: 'فاتورة صيدلية',
    ticketAction: 'صرف روشتة / بيع دواء 💊',
    customerLabel: 'المريض / العميل',
    supplierLabel: 'مستودع وشركة الأدوية',
    categoryLabel: 'التصنيف الدوائي'
  },
  defaultCategories: ['أدوية ومضادات', 'فيتامينات ومكملات', 'عناية بالبشرة', 'أجهزة ومستلزمات طبية'],
  quickServices: [
    { name: 'قياس ضغط وسكر', price: 15, icon: '🩺' },
    { name: 'توصيل روشتة طارئة', price: 20, icon: '🛵' }
  ]
});
```

ثم أضف السطر التالي في `index.html` و `build.js`:
```html
<script src="js/profiles/profile-pharmacy.js"></script>
```
سيظهر النشاط فوراً في شاشة **الإعدادات -> نشاط المنشأة والتشكيل**، ويمكن لأي عميل أو مدير تفعيله بنقرة واحدة!

## 🛡️ عزل البيانات والأمان (Storage Isolation)

النواة تعتمد البادئة `mterp_*` لجميع مفاتيح التخزين المحلي والجلسات (`mterp_cache_*`، `mterp_session`، `mterp_audit_logs`، إلخ).
هذا يضمن استقلالاً تاماً عن أي نظام آخر أو عن النسخة الرئيسية لميكروتك صيانة.
