# دليل النسخة المهيكلة معمارياً (Modular Architecture Guide)

مرحباً بك في النسخة المهيكلة معمارياً من **ميكروERP**. تم تفكيك ملف الكود الضخم القديم (~30,000 سطر) إلى هيكل موديولي منظم وموزع هندسياً وفق أحدث معايير هندسة البرمجيات النظيفة (Clean Architecture).

## 🚀 كيفية التشغيل والتطوير

### 1. وضع التطوير الموديولي (Modular Development Mode)
* يمكنك فتح الملف [`app-modular/index.html`](file:///Users/M1/Desktop/microtech-app/app-modular/index.html) مباشرة في المتصفح أو عبر أي خادم محلي.
* عند تعديل أي ميزة (مثلاً نقطة البيع أو الحسابات)، افتح الملف المخصص لها فقط (مثلاً `15-pos-retail.js` أو `17-accounting-finance.js`) دون الحاجة لتصفح 30,000 سطر.

### 2. وضع التجميع والإنتاج (Production Bundle Mode)
> ⚠️ **تحذير أمني وهندسي هام:** مسار البناء الوحيد المعتمد للمشروع هو `node app-modular/build.js`. لا تعدّل `app-modular/dist/index.html` يدوياً أبداً لأنه مُولَّد بالكامل، وأي تعديل يدوي فيه سيُمحى في البناء التالي. تم حذف أي سكربتات مزامنة عكسية قديمة لحماية مصادر الكود الموديولية.

عند رغبتك في توليد ملف واحد مدمج محمي للتشغيل دون الحاجة للمجلدات:
افتح الطرفية (Terminal) واكتب:
```bash
node app-modular/build.js
```
* سيتم تجميع كافة الملفات وفحص سلامتها برمجياً بنسبة 100% خلال أقل من 100 ميلي ثانية.
* سينتج الملف النهائي في: [`app-modular/dist/index.html`](file:///Users/M1/Desktop/microtech-app/app-modular/dist/index.html).
